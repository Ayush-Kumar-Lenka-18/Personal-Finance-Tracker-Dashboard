# Personal Finance Tracker Dashboard

## Project Overview

The Personal Finance Tracker Dashboard is a data analytics project designed to analyze personal financial transactions and provide meaningful insights into spending behavior. The project uses data visualization techniques to identify expenditure patterns, major spending categories, and monthly financial trends.

## Objectives

- Analyze personal financial transactions
- Categorize expenses and income
- Visualize spending patterns
- Track monthly financial trends
- Support better budgeting decisions

## Dataset Information

Source: Kaggle Personal Finance Dataset

Dataset Size:
- 806 Records
- 7 Features

Features:
- Date
- Description
- Amount
- Transaction Type
- Category
- Account Name
- Month

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Data Exploration
- Transaction Type Analysis
- Category-wise Expense Analysis
- Monthly Trend Analysis
- Dashboard Summary Generation

## Visualizations

- Bar Chart
- Pie Chart
- Monthly Trend Line Chart

## Results

The analysis revealed that debit transactions significantly outnumbered credit transactions. Major spending categories included Mortgage & Rent, Home Improvement, and Groceries. The dashboard successfully highlighted spending patterns and monthly expenditure trends.
